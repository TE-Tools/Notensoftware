MusicXML analysieren

Erster Baustein: eine MusicXML-Datei hochladen und die enthaltenen Stimmen sowie deren Tonumfang anzeigen. Kompositions-/Arrangement-Vorschläge folgen später.



    
MusicXML erzeugen

    
Zweiter Baustein: aus einer Vorgabe eine fertige MusicXML-Datei bauen. Hier erst
      mal ein festes Testbeispiel (C-Dur-Tonleiter, eine Stimme) — später mit Eingabefeldern.


    
    


    
KI-Komposition / Arrangement

    
Dritter Baustein: aus einer kurzen Idee lässt Claude ein komplettes, spielbares
      Stück entwerfen (Form, Motiv, Instrumentation) — die eigentliche MusicXML-Datei
      baut weiterhin unser eigener, getesteter Code daraus.


    

      
      
      
      
      
      
    

    
Viele Takte × viele Instrumente können die Antwortlänge der KI
      sprengen — dann kommt eine klare Fehlermeldung statt eines kaputten Ergebnisses.
      Im Zweifel lieber weniger Instrumente oder in zwei Durchgängen komponieren.
